# Privacy Policy — 117HD Discord Bot

This bot does not collect, store, or sell any personal data.

## Message content

We only read message content when you upload a `.log` file attachment in the
117HD Discord server, in order to detect known RuneLite error messages and
reply with the relevant troubleshooting steps. The file is processed in
memory and deleted immediately after a reply is sent — we do not keep a copy.

## Opting out

Run `/optout` in the server at any time to stop the bot from scanning `.log`
files you upload. Run `/optin` to resume. This preference is stored only as
your Discord user ID — no message content is stored alongside it.

## Data storage

No message content, log files, or user data are stored off-platform
(outside of Discord) or in any database.

## AI/ML training

No data handled by this bot is used to train AI or machine learning models.

## Third parties

No data is shared with third parties.

## Questions

Open an issue on our GitHub: https://github.com/117HD/discord-bot
